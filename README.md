# Odin Todo List

This project was created for the Odin Project with the purpose of building a Todo List app using vanilla HTML, CSS, JavaScript, and Webpack. This project had a particular focus on using OOP principles.

## This project contains:
* A sidebar where you can toggle project tabs, delete project tabs or edit the names of projects, or toggle special options to display todos.
* A main content section to display todo tabs with basic information about todos and an ability to view more information about the todo or delete the todo from the project.
* Display for more information about each todo that can be opened. 
* A button that opens a dialog with a form for users to input new todos.

## Concepts used for this project:
* Previous HTML/CSS concepts
* JavaScript classes, objects, factory functions, IIFE
* DOM rendering with JavaScript
* ES6 Modules, Import/Export
* npm, package.json
* Bundling with Webpack
* Loading HTML, CSS
* JSON object and methods
* localStorage API
* OOP principles
